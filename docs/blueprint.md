# **App Name**: MarketNest

## Core Features:

- Secure User Authentication: Facilitates user sign-up, login, and session management using email/password and Google accounts, integrated with Firebase Authentication.
- Ad Creation & Publishing: Allows users to create detailed classified ads, including a title, description, category, price, and upload multiple images (stored in Firebase Storage).
- Smart Ad Description Tool: An AI-powered tool that provides suggestions to enrich ad descriptions or generates relevant keywords based on initial user input (title, category) to optimize listings.
- Ad Browsing & Filtering: Enables users to explore listings through categories and subcategories, and filter results by keywords, location (city/region), and price range.
- Personalized User Profiles: Dedicated profile pages displaying user contact information (optional), their published ads, and a list of their favorited listings.
- Saved Favorites: Users can bookmark ads of interest for easy access later from their profile.
- Basic Admin Console: A backend interface for authorized users to view, manage, and moderate ads and user accounts.

## Style Guidelines:

- Primary color: A vibrant, trustworthy blue (#1D64C9), chosen to convey reliability and a modern aesthetic, standing out against a light background.
- Background color: A very light, subtle bluish-grey (#F0F2F5) that provides a clean and open feel, enhancing readability without distracting from content.
- Accent color: A lively turquoise (#2BEEDE), providing a distinct and energetic highlight for calls to action and interactive elements.
- Primary font: 'Inter' (sans-serif) for all text elements. Its modern, neutral, and highly readable characteristics are ideal for extensive content found in a classifieds marketplace.
- Utilize a set of modern, clear, and consistent line icons that enhance user navigation and interface clarity. Consider using filled versions for active or selected states.
- Implement a responsive, clean, and intuitive grid-based layout for displaying ad listings, prioritizing ad imagery and essential information. Navigation should be streamlined for category browsing and search.
- Incorporate subtle and smooth transitions for page loading, filtering actions, and interactive elements such as hover states on ad cards, ensuring a fluid user experience.
